# CenNavi

**현재 웹페이지를 이해하고, 필요한 정보를 찾고, 사용자가 확인한 입력·클릭을 수행하는 AI 브라우저 도우미입니다.**

Chrome 사이드 패널에서 질문하고, 화면의 안내 표시와 실행 계획을 확인합니다. 개발·시험 환경의 URL과 계정 ID도 찾아볼 수 있습니다.

현재 버전 **0.8.2** · Chrome **114 이상** · Manifest V3 · Gemini API

캡처는 로컬 미리보기와 가짜 AI 응답으로 만들었습니다. 실제 업무 시스템을 조작한 화면이 아닙니다.

## 주요 기능

- **페이지 질문·요약·번역**: 현재 화면의 텍스트·구조와 보이는 영역의 스크린샷을 참고합니다. 선택한 글에 대해서도 질문할 수 있습니다.
- **실시간 답변**: 답변을 생성되는 대로 표시하고, 필요하면 중지합니다. 중단되거나 완성되지 않은 응답으로 실행 계획을 만들지 않습니다.
- **화면 안내**: 메뉴·링크·입력칸·버튼에 순서와 설명을 표시합니다.
- **확인 후 실행**: 일반 입력칸에 텍스트를 입력하고 클릭·Enter를 수행합니다. 먼저 계획을 보여주며 **실행**을 눌러야 동작합니다.
- **작업 이어가기**: 클릭·Enter 뒤에는 멈춥니다. **결과 확인 · 다음 단계**를 누르면 같은 탭의 새 화면을 읽고 다음 계획을 제안합니다. 다음 실행도 확인이 필요합니다.
- **환경·계정 조회**: 등록된 개발·시험 환경과 계정 ID·메모를 조회하고 ID를 복사합니다. 등록 환경에 따라 툴바에 `DEV`·`TEST` 배지가 표시됩니다.
- **대화 기억·복원**: 최근 대화를 참고하고 브라우저에 기록을 저장합니다. 새 대화로 지우거나 Markdown 파일로 내보낼 수 있습니다.
- **정리된 대화 UI**: 여러 줄 입력창, 요청 하나당 작업 카드 하나, 접힌 실행 기록, 필요할 때 여는 도구·설정 창, 다크 모드를 제공합니다.

## 설치 및 AI 연결

1. 이 저장소를 다운로드하거나 복제합니다.
   ```powershell
   git clone https://github.com/choisunghwan/cenNavi.git
   ```
2. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 `manifest.json`이 있는 프로젝트 폴더를 선택합니다.
4. 툴바의 **CenNavi** 아이콘을 눌러 사이드 패널을 엽니다.
5. 우측 상단 **⋯ → 설정**에서 Gemini API 키를 입력하고 **저장하고 연결 테스트**를 누릅니다.

기본 모델 설정값은 `gemini-2.5-flash`입니다. 설정에서 모델 이름을 변경할 수 있습니다. API 키 없이도 메뉴의 환경·계정 조회는 사용할 수 있습니다.

코드를 업데이트한 뒤에는 확장 관리 화면에서 CenNavi의 **새로고침(↻)** 을 누르고, 열려 있던 패널을 닫았다가 다시 여세요. **⋯ → 진단**에서 적용된 버전과 연결 상태를 확인할 수 있습니다.

## 사용 방법

### 대화와 페이지 도구

입력창에 바로 질문하세요.

```text
이 화면에서 무엇을 할 수 있어?
주문 조회 메뉴는 어디에 있어?
이 페이지의 핵심 내용을 정리해줘
```

첫 화면의 추천 또는 **⋯ 메뉴**에서 요약·선택·번역을 실행할 수도 있습니다. 선택 영역 질문은 페이지에서 글을 드래그한 다음 실행하세요.

**Enter**로 전송하고 **Shift+Enter**로 줄을 바꿉니다. 답변 대기 중에는 전송 버튼이 중지 버튼으로 바뀝니다. 참고 화면과 실행 내역은 필요할 때 펼쳐 볼 수 있습니다.

### 입력·클릭과 다음 단계

```text
고객명에 김철수 입력하고 조회해줘
```

1. CenNavi가 현재 화면을 읽고 실행할 대상과 동작을 작업 카드에 표시합니다.
2. 내용을 확인한 뒤 **실행**을 누르거나 **취소**합니다.
3. 동작 후 **결과 확인 · 다음 단계**를 누르면 원래 요청과 새 화면을 함께 분석합니다.
4. 다음 동작이 필요하면 같은 카드에 새 계획이 나타납니다. 이전 단계는 실행 기록으로 접힙니다.

한 계획은 최대 4개 동작이며, 입력 문자열은 최대 100자입니다. 클릭·Enter 뒤에는 현재 실행 묶음을 종료합니다. 완료 여부는 화면에 보이는 근거를 바탕으로 설명하며, 업무 성공을 보장하는 자동 판정은 아닙니다.

### 환경·계정과 대화 기록

- **⋯ → 로그인**: 현재 사이트의 환경과 계정 ID를 봅니다.
- **⋯ → 환경**: 등록된 전체 환경을 조회합니다.
- **상단 ＋**: 저장된 대화와 현재 작업을 지우고 새 대화를 시작합니다.
- **⋯ → 대화 내보내기**: 질문·답변을 `CenNavi-대화.md`로 저장합니다.
- **⋯ → 진단**: 버전·사이트 권한·화면 읽기·스크린샷·Gemini 연결을 점검합니다.

슬래시 명령도 지원합니다.

| 명령 | 동작 |
|---|---|
| `/요약` | 현재 페이지 요약 |
| `/번역` | 선택 영역 또는 페이지 한국어 번역 |
| `/선택 [질문]` | 선택한 글에 질문 |
| `/분석 [질문]` | 현재 화면 설명·안내·실행 계획 |
| `/로그인 [주소]` | 현재 사이트 또는 지정 주소의 계정 조회 |
| `/환경 [키워드]` | 등록 환경 조회·검색 |
| `/설정` · `/진단` · `/도움말` | 설정·연결 점검·사용법 |
| `/지우기` | 대화 초기화 |

## 지원 범위와 제한

| 구분 | 현재 동작 |
|---|---|
| 일반 웹 입력칸·텍스트 영역 | 입력·Enter·클릭 지원. 사이트 구현에 따라 제한될 수 있습니다. |
| 날짜 선택기·복잡한 자동완성·그리드·드롭다운 | 전용 조작 미지원 또는 제한적 |
| iframe·Shadow DOM 내부 | 화면 요소 읽기·직접 조작 미지원 |
| 여러 페이지 작업 | 사용자가 결과 확인과 다음 실행을 확인하는 방식. 무인 자동 실행은 미지원입니다. |
| 비밀번호 입력·삭제·결제·전송 등 | 자동 실행을 제한하고 직접 수행하도록 안내합니다. |
| 운영 환경 | 등록된 `prodPatterns`에 일치하면 차단합니다. 모든 운영 사이트를 자동 식별하는 것은 아닙니다. |
| Chrome 내부 페이지·웹스토어 | Chrome의 접근 제한으로 분석할 수 없습니다. |
| 긴 페이지 | 본문 최대 24,000자, 선택 영역 최대 12,000자, 표 최대 5개·각 최대 30행 범위에서 읽습니다. 전체 문서가 항상 포함되지는 않습니다. |

## 데이터와 저장

- 분석할 때 페이지 텍스트·구조·선택 영역·스크린샷, 해당 환경의 계정 ID·메모, 최근 대화가 **Gemini API로 전송**됩니다. 입력칸의 값은 구조 정보로 수집하지 않지만 화면 캡처에 보이는 정보는 포함될 수 있습니다. 자동 민감정보 가림 기능은 없습니다.
- API 키·모델 설정과 최근 60개 대화 메시지는 브라우저 로컬 저장소에 저장합니다. 후속 분석은 최근 16개 메시지를 참고하며, 메시지당 최대 4,000자를 전송합니다.
- 스크린샷과 실행 가능한 계획은 대화 기록으로 저장·복원하지 않습니다. 패널을 다시 열면 계획은 새로 요청해야 합니다.
- `<all_urls>` 사이트 접근 권한을 사용합니다. 화면 읽기와 캡처는 분석 요청 시 수행하며, 환경 배지는 탭 이동에 따라 갱신됩니다.
- 이름이 CenNavi로 바뀌어도 기존 저장소 키는 유지하므로 같은 설치의 API 설정과 대화 기록을 이어서 사용합니다.

환경과 계정 샘플은 `shared/sample-pack.js`에서 수정한 뒤 `npm run build`로 백그라운드 실행 파일을 다시 생성합니다. 계정은 모두 가상의 예시이며, 비밀번호는 등록하지 않습니다. `shared/local-config.js`는 선택적인 로컬 설정 파일로 Git에서 제외됩니다. 파일을 공유할 때 키가 포함된 로컬 설정은 제외하세요.

## 연습 사이트와 미리보기

프로젝트 폴더에서 연습용 주문 관리 사이트를 실행합니다.

```powershell
python -m http.server 8080 --bind 127.0.0.1 --directory demo-site
```

Chrome에서 `http://localhost:8080`을 열고 CenNavi 패널로 질문해 보세요. 이 주소는 샘플 개발 환경으로 등록돼 있습니다.

UI만 살펴보려면 다음 서버를 실행합니다.

```powershell
python -m http.server 8099 --bind 127.0.0.1
```

- `http://localhost:8099/extension/preview.html`: 확장 API를 흉내 내는 UI 미리보기. 실제 사이트를 조작하지 않습니다.
- `http://localhost:8099/web/index.html`: 환경·계정 조회용 웹 화면. 다른 탭의 화면 분석은 지원하지 않습니다.

## 문제 해결

| 증상 | 확인할 내용 |
|---|---|
| 확장 관리에 빨간 **오류** 버튼 표시 | 상세 메시지를 확인하세요. 이전 오류 기록도 남아 있을 수 있습니다. 업데이트 후 새로고침하고 기존 기록을 지운 다음, 같은 오류가 새로 발생하는지 확인합니다. |
| `No tab with id` | 0.8.1에서 탭 종료 직후의 조회·배지 갱신 실패를 처리하도록 수정했습니다. 이전 버전이면 새로고침해 업데이트하세요. |
| 백그라운드의 `importScripts`·`sample-pack.js` 로딩 실패 | 0.8.2에서 서비스 워커를 단일 실행 파일로 변경해 런타임 공유 스크립트 로딩을 제거했습니다. 업데이트 후 **↻ 새로고침**하고 버전이 0.8.2인지 확인하세요. 새 워커 경로는 `extension/background.bundle.js`입니다. |
| 화면을 읽지 못함 | 일반 HTTP/HTTPS 페이지에서 **⋯ → 진단**을 실행하고 사이트 접근 권한을 확인합니다. |
| 답변 실패 | API 키·모델·Gemini 오류 메시지를 확인합니다. 분석 요청은 60초 뒤 시간 초과로 종료됩니다. |
| 탭이 바뀌었다는 메시지 | 작업하던 탭으로 돌아와 로딩이 끝난 뒤 다시 확인합니다. 다른 탭에서는 기존 계획을 실행하지 않습니다. |

## 개발 구조와 검증

| 경로 | 역할 |
|---|---|
| `manifest.json` | 확장 설정·권한·버전 |
| `extension/` | 사이드 패널, 배지 서비스 워커, 페이지 읽기·표시·동작 실행 |
| `extension/background.js` → `background.bundle.js` | 편집용 워커 소스 → 환경 데이터·매칭 코드까지 포함한 실제 실행 파일 |
| `scripts/build-background.cjs` | 외부 라이브러리 없이 단일 워커 파일 생성·최신 상태 검사 |
| `shared/` | 대화 UI·기록, Gemini 호출·스트리밍, 환경 매칭·샘플 데이터, 스타일 |
| `web/` · `demo-site/` | 웹 조회 화면·연습 사이트 |
| `tests/` | 단위 테스트·로컬 UI 테스트·확장 로딩 검사 |

배포 소스에는 생성된 실행 파일이 포함됩니다. `shared/sample-pack.js`, `shared/match.js`, `extension/background.js`를 수정했다면 먼저 다시 빌드하세요. 단위 테스트는 실행 파일의 최신 상태를 검사하고 Node.js 내장 테스트 러너를 사용합니다.

```powershell
npm run build
npm test
```

브라우저 테스트는 Playwright와 Chrome이 필요합니다. 실제 AI 요청은 가짜 응답으로 대체합니다.

```powershell
# 별도 설치 경로를 쓸 때만 지정
$env:PLAYWRIGHT_PATH = "Playwright 패키지의 절대 경로"
npm run test:browser

# Chromium의 별도 임시 프로필에서 실제 확장 로딩·탭 종료·같은 프로필 재시작 검사
# 필요하면 실행 파일 경로 지정
$env:CENNAVI_CHROMIUM_PATH = "Chromium 실행 파일의 절대 경로"
npm run test:extension
```

확장 로딩 검사는 사용자 Chrome 프로필을 사용하지 않습니다. 실제 Gemini 응답 품질과 개별 사내 시스템의 호환성은 별도로 확인해야 합니다.
